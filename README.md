# E-Commerce REST API

Backend-based E-Commerce application developed using Flask and SQLite.

## Features
- User Registration
- User Login Authentication
- JWT Security
- Product Management
- Cart System
- Order Placement
- Inventory Management
- Product Recommendation System

## Technologies Used
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- JWT Authentication
- Bcrypt
- Postman
- Git & GitHub

## APIs Implemented

### Authentication APIs
- POST /register
- POST /login

### Product APIs
- POST /add_product
- GET /products

### Cart APIs
- Add to cart
- View cart
- Remove from cart

### Order APIs
- POST /place_order
- GET /orders

### Recommendation API
- GET /recommend/<max_price>

## Project Outcome
Successfully developed a secure backend e-commerce system with authentication, inventory management, ordering system, and recommendation functionality.
