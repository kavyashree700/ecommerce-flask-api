# E-Commerce REST API

A backend-based E-Commerce system developed using Flask and SQLite.

## Features
- User Authentication
- Product Management
- Cart System
- Order Management
- Recommendation System

## Tech Stack
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- JWT Authentication
- Postman
- Git & GitHub
